Good to know

Do my files leave my browser?

No. Every PDF tool on this page runs 100% on your device using open-source libraries (pdf-lib, pdf.js). Nothing is uploaded, stored, or tracked. See the privacy policy.

Is there a file size limit?

Only what your device's memory allows. Very large PDFs (hundreds of MB) may be slow on phones — for those, a desktop browser works best.

What about password-protected PDFs?

Encrypted PDFs can't be processed in the browser — you'll see a clear error. Unlock the file first, then use the tool.
